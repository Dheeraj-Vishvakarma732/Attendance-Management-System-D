Attendance Management System

A simple Python-based Attendance Management System built using Tkinter.

Features

- Enter student name and roll number
- Mark attendance as Present or Absent
- Save attendance records in a CSV file
- View attendance records in a table
- Prevent duplicate attendance for the same student on the same day

Technologies Used

- Python
- Tkinter
- CSV

How to Run

1. Install Python on your computer.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

python app.py

Data Storage

Attendance records are saved in "attendance.csv".
